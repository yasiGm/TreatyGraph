TreatyGraph

Pick two countries and see how their relationship unfolded since 1816: alliances, wars, diplomatic ties and who was in charge.

Read this before trusting a blank timeline. “No records” means the datasets below contain nothing for that pair or period. It does not mean nothing happened. Coverage differs by source and several sources stop years ago (see the coverage bars on each pair page).

Sources: Correlates of War (Formal Alliances v4.1; Inter-State War Data v4.0; Intra-State War Data v4.1; Diplomatic Exchange v2006.1; State System Membership v2024), ATOP 5.1 (Leeds et al.), Archigos 4.1 (Goemans, Gleditsch & Chiozza; pilot countries only). Country identity and borders follow COW state-system membership. Built for portfolio / non-commercial use. Data are served from SQL Server through an ASP.NET Core API; see the README for citations and licence notes.
