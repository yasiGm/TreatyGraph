# data/

No third-party data is stored in this repository. see "Data files" in the main README for what to put where and where to get it.

The datasets (Correlates of War, ATOP, Archigos) are not covered by the AGPL that applies to the code and stay under their owners' terms (COW data are for non-commercial use; Archigos asks users to cite Goemans, Gleditsch and Chiozza 2009, *Journal of Peace Research* 46(2): 269-283).
